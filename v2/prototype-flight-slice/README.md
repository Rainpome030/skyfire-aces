# Three.js 飞行切片原型

> **PROTOTYPE — 可丢弃代码，不是正式 v2。**

原始验证问题：**哪种镜头与高度表达，能让有限操作的俯视空战同时保持舒适、可读和有战术选择？**

## 镜头裁决（2026-08-18）

- **采用 A：地图朝上 + 世界方向稳定 + 低 FOV 透视。**
- 用户反馈 A 与 C 体验都很好，最终选择 A。
- C 是可行备选而非失败方案；B 未收到明确负面评价。
- B、C 和原型切换器已删除，后续 Agent 不应重新打开镜头选型，除非出现新的试玩证据。

本目录仍是用于验证高度、操控和战斗关系的可丢弃切片，不能直接提升为正式 v2。2026-08-19 的展示版把验证内容组织成一个约三分钟的完整单关，但没有把原型误升格为生产架构。


## 操作

- `A / D`：左右转向
- `W`：加力延伸，以更大的转弯半径换取速度
- `S`：减速急转，短时间提高转向率；持续过久会掉到低效速度区
- `Space`：低空/高空切换
- `E`：发射导弹
- `R`：重新开始
- 鼠标在战场左右两侧按住：转向
- 手机在战场任意位置拖动：左右转向、上推加力、下拉急转

机炮在敌人进入机头射界且高度允许时自动进行五发短点射；持续稳定压住目标会触发一次更强的扫射回报。导弹有四枚：360° 雷达会先显示接触，目标进入机头前方约 ±100° 后由火控黏着捕获，进入 ±75° 才建立 `LOCK`，继续保持在 ±25° 可获得杀伤与制导更强的 `PERFECT`。`LOCK` 已经可以开火，不需要为了追求 `PERFECT` 错过窗口。

发射后的导弹是模拟层中的真实实体，会先离架、再点火转弯，并且只在实际碰撞时结算伤害；快速点按在锁定完成前还有一个很短的输入缓冲。低空可以攻击地面防空炮，但会暴露在预测弹着点的防空火力下；拉高可以脱离地面火力，空中敌机则会在 14–38 的连续高度带内机动。空中火控根据敌我实际高度差判断，雷达仍会保留高度不合适的接触，并显示目标位于上方或下方。每局只有一次救援复位。

没有增加“滚筒”或“悠悠”按钮。玩家将 A/D、W/S 与 Space 组合成真实航迹，系统只在战术结果成立后确认机动：俯冲攻击后拉起是 Boom & Zoom；对不同高度的空中目标完成一次改善角度/距离的高度往返，可形成高/低悠悠；敌机攻击承诺期间用 S + 转向 + 高度转换迫使其冲前，可形成防御滚转，随后反向转弯并多次交叉可继续形成反转和剪刀机动。迎头交会前提前转入、交会后取得机头角度则会识别抢先转弯。识别不会提供无敌帧，也不会替玩家驾驶。

## 单关结构

1. **低空突入**：先打雷达会延长防空解算窗口；冒险先打防空炮则获得更高路线分。
2. **错层拦截**：长机维持高位、僚机下沉，攻击前有可规避的三维射击航线预告。
3. **交叉猎场**：在地面阵地与纵向追击的王牌之间主动选择航迹；王牌半血后进入更快、更大高度摆幅的第二阶段。

桌面与手机使用同一套模拟规则。速度就是能量状态：加力会扩大转弯半径，减速急转会快速消耗速度，松开后自动回到巡航，不额外增加资源条。敌机开火后必须沿三维攻击线承诺一小段时间；玩家若用急转或防御滚转让它冲过头，会得到短暂 `ADVANTAGE`，加快机炮与导弹解算。手机仍只保留高度和导弹两个主动按钮，战场上的动态二维操纵区承担连续机动；竖屏和横屏都有独立 HUD 布局。演习结束后会展示高度切换、导弹命中、承伤、迫使冲前、识别机动和救援复位等复盘指标。

## 验证门槛

- 连续十分钟无明显眩晕。
- 高度在不读数字时仍可由阴影、云层与遮挡判断。
- 玩家会主动利用高度攻击或避险。
- 拖尾说明速度和转向，不淹没战场。
- 地面、普通截击机与王牌形成可以复盘的取舍。
